# Third-party software

ImagePrep itself is MIT licensed. Its dependencies retain their own licenses.
This is a short inventory of the runtime dependencies; the package lock records
the full dependency tree and exact installed versions.

| Runtime dependency | Purpose | License |
| --- | --- | --- |
| React / React DOM | Interface rendering | MIT |
| Lucide React | Interface icons | ISC |
| JSZip | ZIP downloads | MIT or GPL-3.0-or-later; used under MIT |
| DM Sans via Fontsource | Self-hosted variable typography | SIL Open Font License 1.1 |

The installed packages contain license texts. See the respective upstream
repositories: [React](https://github.com/facebook/react),
[Lucide](https://github.com/lucide-icons/lucide), and
[JSZip](https://github.com/Stuk/jszip).

Vite, TypeScript, Vitest, Playwright, and axe-core are development tools, not
external services used to process images. There are no paid runtime services.
The included sample landscape is original Canvas artwork generated by the app.

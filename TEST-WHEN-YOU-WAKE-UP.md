# Test ImagePrep when you wake up

1. Double-click `START-IMAGEPREP.cmd`. Keep its terminal open while using the app.
2. Click **Try a sample image**, then **Prepare images**. Open the thumbnail preview
   and download the result.
3. Add a few of your own JPG/PNG/WebP images. Try a 600 × 600 maximum and confirm
   the proportions stay intact.
4. Convert a transparent PNG to JPEG. Pick a background color and check the result.
5. Prepare several images and use **Download all**. Extract the ZIP and open the
   images. Identical names should produce separate files.
6. Change the format or dimensions after preparation. Old downloads should disappear
   until you prepare the images again.
7. Try a broken or unsupported file, then a valid file. The error should be clear
   and the valid file should still work.
8. Narrow your browser window or test on your phone after hosting it. The interface
   should remain readable and usable.

If something fails, tell me the browser, input format and dimensions, settings,
steps, expected result, and what happened. A non-private sample file is helpful
when the issue depends on a particular image.

Image contents are kept only for the current page session. Refreshing clears the
workspace. This release has not been published to GitHub or a public website.

See `README.md` for commands, architecture, limits, and publication instructions.
